## 1. 联合场景

新增 test/workflow-integration.test.js 的四项公开接口测试。工具通过实际 main.js 执行，扩展通过实际事件回调处理；pi 文件网关由同一临时项目的 createProjectFs 夹具提供。面板与扩展使用独立受限文件实例和现有协调器。测试文件存入会话临时目录并清理。

| 场景 | 实际核对 |
|---|---|
| 旧 Markdown → 自动正文 → 比较 → 聊天批准事件夹具 → 任务恢复 | 未带 updated 的条目保持原文，卡片日期回退；候选正文/版本完整；批准前无正式新增；共存关系双向；待审身份清除；压缩后当前正式新正文出现；finish 完成；Plan/Goal 只读动作及结果追踪磁盘零变化 |
| 导入 → 未分析 → 聊天暂缓 → 面板批准 | 未分析保存拒绝；暂缓仍 pending；面板明确批准后才写入；来源 ID、旧日期和外国项目链接不继承；任务索引核对实际决定 |
| 聊天拒绝 → 决定账本 → 相同建议抑制 → 新依据 | 拒绝记 actor=user；相同已分析建议不产生第二张卡，不写正式记忆；变化依据可重新提出，再经面板批准保存 |
| 旧批次 → 重新展示 → 并发编辑 → 旧批准拒绝 → 重启信任丢失 → 再分析 | legacy 批次展示升级到 revision 2，仍不可直接保存；同 baseHash 的两个面板编辑只允许一个成功；旧目标批准 E_TARGET_STALE；清除进程凭据后旧 token E_APPROVAL_STALE；重新比较当前胜出正文后批准，保留旧正文及替代关系 |

上述“聊天批准”使用实际 tool_call/tool_result 接口的答案夹具，**不是用户在已安装宿主中的点击**。重启是重置进程内凭据/会话状态并读取持久状态的模拟，不是完整宿主重启。

已有真实子进程竞争测试继续覆盖共享更新、同批次只发布一条、同目标版本只允许一个胜出和持有者退出恢复。新增联合路径与这些测试各自证明其边界，不宣称完整主进程/侧车进程端到端竞态或电源中断事务已验证。

## 2. 旧数据兼容与失败行为

- 旧正文/日期读取、独立导入、legacy review 升级、部分保存身份恢复及跳过决定保留已有回归。
- 批次重启失去分析信任后需重新分析，旧批准不能迁移；重新展示不是自动批准。
- 比较与批准绑定 current source/hash；目标或提案变化需重新比较和批准。旧卡、篡改卡、跨项目 token 等失败路径保留。
- 未审、暂缓、拒绝、重复、保存分别处理；暂缓保持待审，未选不拒绝；正式写入仍人工批准。
- 确定性正文比较保留大小写、Unicode 和缩进；同名不代表替代。有限三条候选不保证语义完整。
- 状态读取/写入/检索失败产生可见诊断，任务失败回退内存；不会授予批准或把失败称为空语料。
- 原有异常地图明确拒绝，未进行未经批准的历史迁移。

阶段六运行未复现新的生产缺陷。联合用例初次运行的旧日期断言曾混淆解析层与 cardOf 的日期回退；核对现有实现与测试后修正测试预期，生产代码未改变。

## 3. 上下文成本路径

可复现脚本：node test-support/workflow-costs.cjs。夹具为四条置顶英文正文，每条 11,556 UTF-16 字符。结果保存到会话临时目录 phase6-costs.json。

| 路径 | 本次实际字符数 | 说明 |
|---|---:|---|
| 自动首请求新增 | 3,849 | 含任务索引、版本/截断和分隔 |
| 自动同阶段重复 | 3,849 | 字节一致；缓存不消除发送的字符，计费取决于 provider |
| 自动续接请求新增 | 7,698 | 最多最后两个阶段块；不超过 8,000 |
| 压缩后无用户消息恢复新增 | 3,851 | 附清晰数据消息，不改助手摘要 |
| search 返回序列化 JSON | 1,951 | ID/摘要/诊断等，不含正文 |
| load 返回序列化 JSON | 12,098 | 正文 11,556，其余结构元数据 |
| prepare 返回序列化 JSON | 26,393 | **正文 24,000**，三个候选；正文预算不限制整个工具 JSON |
| 三次分页正文总和 | 10,668 | 完成三个候选余下部分 |
| 三次分页 JSON 总和 | 12,465 | 另含身份、来源、hash、覆盖等 |

自动注入上限是每请求新增 8,000 UTF-16 字符，含分隔符；每块最多三条正文、每条 2,000。生产正文块最多 3,998，预留两个换行字符。比较准备正文预算 24,000，每候选/页 8,000；load 正文采用已有 20,000 上限。

固定 GUIDANCE、原始会话历史、工具描述、候选元数据、分析依据、批准卡和分页返回均可能增加模型上下文。页面完整原文/diff 只在面板展示时不直接进入 provider；Agent 工具返回及卡片参数仍可进入会话。

**没有运行模型 tokenizer，也没有测量实际 provider token 账单、缓存折扣、延迟或吞吐；不将字符数换算为 token，不声称性能提升。** 多阶段缓存稳定可通过字节比较证明，provider 的真实缓存命中需要安装态/请求计费证据。
